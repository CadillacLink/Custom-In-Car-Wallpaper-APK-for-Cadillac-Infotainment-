## Installation 安装教程
1. Download the APK file to your USB drive. 将APK下载至U盘
2. Enable install unknown apps on your Cadillac infotainment system. 在车机开启未知来源应用安装权限
3. Open APK and complete installation. 打开APK完成安装
4. Launch app, import picture to set wallpaper, switch language in settings.
   启动App，导入图片设置壁纸，在设置页切换语言
