## Compatibility 适配说明
This application is developed for technical research.
It requires an in-vehicle infotainment environment that supports Android APK installation.
Whether your device allows APK installation depends on your vehicle's original system restrictions.

本应用仅为技术研究开发。
程序运行前提是你的车机环境本身支持安卓APK安装。
设备能否安装APK，取决于车辆原厂系统限制，本项目不提供任何系统解锁、权限破解相关教程。

> No installation guide for unlocking or bypassing factory restrictions will be provided.
> 本项目**不提供任何解锁、绕过原厂系统限制的安装操作教程**。
